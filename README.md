# Wall

A native iPad wall display and its Python/browser server: editable widgets and GIFs, photo booth and gallery, shared canvas, and optional music/voice integrations.

This is an independent, sanitized source distribution. It contains only Wall app/server source, synthetic tests, small bundled decorative GIFs, and setup examples. No other project archives or inherited repository history are included. Photos, guest details, saved layouts, account/device tokens, credentials, signing material and installation packages are excluded.

Start with [SELF_HOSTING.md](SELF_HOSTING.md) for the server and [IPAD_SETUP.md](IPAD_SETUP.md) for building and installing the iPad app. The generated Xcode project is included; XcodeGen is needed only when regenerating it after project.yml changes.

No instance is deployed by this export. Optional provider accounts and voice are unconfigured. Keep the repository private until the owner approves a recipient, access and any redistribution license. No open-source license has been granted. Bundled GIF provenance is recorded in GIF_SOURCES.md; source URLs do not establish redistribution rights.

See SOURCE_INVENTORY.json for the complete file/hash inventory and VERIFICATION.md for checks and limits.
