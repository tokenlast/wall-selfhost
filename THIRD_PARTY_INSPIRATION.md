# Historical inspiration and prior art

The LED matrix treatment described below was removed from Wall in build 7 in favor of a plain Helvetica clock. No third-party code or assets ship in the current clock.

Wall's native LED clock renderer is original SwiftUI code in this repository. Its bitmap-dot display construction is adapted from the visual language and documented font-map technique of this permissively licensed project; no source files or assets were copied:

- LED Matrix Simulator by Sallar Kaboli — MIT License — https://github.com/sallar/led-matrix-simulator
